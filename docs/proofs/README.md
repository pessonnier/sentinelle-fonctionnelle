# Archives de preuves

Les fichiers `iteration-001.md` à `iteration-007.md` sont des relevés historiques produits avant le renommage du projet en **SentinelleFonctionnelle**.

Ils peuvent donc contenir l’ancien nom `SentinelFonctionnelle`, l’ancien module `sentinelfonctionnelle` et d’anciens chemins ou messages d’erreur. Ces mentions sont conservées afin de ne pas falsifier les commandes exécutées et les résultats observés à la date de chaque preuve.

Pour toute commande ou référence actuelle, utiliser :

- **nom officiel :** SentinelleFonctionnelle ;
- **nom affiché :** Sentinelle Fonctionnelle ;
- **dépôt et paquet :** `sentinelle-fonctionnelle` ;
- **module Python :** `sentinelle_fonctionnelle`.
